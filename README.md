## 🏁 Quickstart

### Prerequisites
- Node.js 18+ (tested on Node v20 / v26)
- npm, yarn, or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/nate2101/agentmatrix.git
cd agentmatrix

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to inspect the application.

### Building for Production

```bash
npm run build
npm run start
```

## 🔒 Security & Compliance

- **Zero Data Retention**: Customer data, code, and financial feeds are never retained for model training.
- **Isolated Sandboxes**: All agent tool evaluations execute in ephemeral, resource-constrained runtimes.
- **Human-in-the-Loop Thresholds**: Configurable autonomy guardrails for high-risk financial or infrastructure mutations.
